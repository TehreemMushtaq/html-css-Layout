# Clark – Personal Portfolio Website

A responsive personal portfolio landing page built using **HTML and CSS**, designed for a web designer profile. This project was created to practice converting a design layout into a fully responsive, multi-section portfolio page.

🔗 **Live Demo:** https://tehreemmushtaq.github.io/html-css-Layout/first%20project.html

## Features

- Responsive navigation bar (Home, About, Resume, Servers, Skills, Project, My Blogs, Contact)
- Hero section with intro text and profile image
- "Hire Me" and "My Works" call-to-action buttons
- About Me section with personal details
- Clean, modern layout styled with custom CSS

## Tech Stack

- **HTML5**
- **CSS3** – custom styling
- **Bootstrap 5.3.3** – layout and responsive grid
- **Font Awesome 6.7.2** – icons

## Project Structure

```
html-css-Layout/
├── bootstrap-5.3.3-dist/       # Bootstrap framework files
├── fontawesome-free-6.7.2-web/ # Font Awesome icon library
├── images/                     # Images used in the page
├── first project.html          # Main HTML file
└── style project.css           # Custom styles
```

## How to Run Locally

1. Clone the repository
   ```
   git clone https://github.com/TehreemMushtaq/html-css-Layout.git
   ```
